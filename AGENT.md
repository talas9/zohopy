# ZohoPy — Agent Reference

Machine-readable reference for AI coding agents. All CLI commands support `--json`.

## CLI Quick Reference

```bash
# Setup & Config
zohopy setup                                    # Interactive OAuth wizard (asks for data center)
zohopy config --json                            # Show configuration
zohopy orgs --json                              # List all organizations
zohopy --org ORG_ID contacts list --json        # Switch org at runtime

# Contacts
zohopy contacts list --json
zohopy contacts list --type customer --json
zohopy contacts get CONTACT_ID --json
zohopy contacts create '{"contact_name":"X","contact_type":"customer"}' --json

# Items
zohopy items list --json
zohopy items get ITEM_ID --json
zohopy items create '{"name":"Widget","rate":50}' --json

# Invoices
zohopy invoices list --json
zohopy invoices list --status sent --json
zohopy invoices get INVOICE_ID --json
zohopy invoices create '{"customer_id":"X","line_items":[{"item_id":"Y","quantity":1}]}' --json
zohopy invoices mark-sent INVOICE_ID --json
zohopy invoices void INVOICE_ID --json

# Bills, Estimates, Expenses, Orders, Taxes, Settings
zohopy bills list --json
zohopy estimates list --json
zohopy expenses list --json
zohopy sales-orders list --json
zohopy purchase-orders list --json
zohopy taxes list --json
zohopy settings preferences --json
zohopy settings currencies --json
zohopy settings templates --json
zohopy settings users --json

# Raw API (escape hatch — any endpoint)
zohopy raw get /books/v3/compositeitems --json
zohopy raw post /books/v3/contacts --data '{"contact_name":"Test"}' --json
```

## Error Handling

```python
from zohopy import (
    ZohoNotFoundError,           # 404
    ZohoValidationError,         # 400 (base)
    ZohoInvalidFieldError,       # 400 code 2 — .field_name
    ZohoDuplicateError,          # 400 code 4
    ZohoEmptyBodyError,          # 400 code 11
    ZohoBusinessRuleError,       # 400 code 4xxx
    ZohoFeatureNotEnabledError,  # 400 code 110xxx
    ZohoResourceDependentError,  # 400 code 36/1004
    ZohoAuthenticationError,     # 401
    ZohoForbiddenError,          # 403
    ZohoRateLimitError,          # 429 — .retry_after
    ZohoServerError,             # 5xx
)
```

## Multi-Currency

All transactions support `currency_id` + `exchange_rate`:

```python
books.invoices.create({
    "customer_id": "...",
    "currency_id": "AED_ID",
    "exchange_rate": 3.67,
    "line_items": [{"item_id": "...", "quantity": 1}],
})
```

## Landed Cost

```python
books.bills.create({
    "vendor_id": "...",
    "is_landed_cost": True,
    "line_items": [{"item_id": "...", "quantity": 1, "rate": 120}],
})
# Response: allocated_landed_costs, unallocated_landed_costs
```

## Environment Variables

All required values are generated by `zohopy setup`.

| Variable | Required | Description |
|----------|----------|-------------|
| `ZOHO_CLIENT_ID` | Yes | OAuth client ID |
| `ZOHO_CLIENT_SECRET` | Yes | OAuth client secret |
| `ZOHO_REFRESH_TOKEN` | Yes | Permanent refresh token |
| `ZOHO_ORGANIZATION_ID` | Yes | Zoho org ID |
| `ZOHO_DATA_CENTER` | Yes | Region: us, eu, in, au, jp, ca, cn, sa |
| `ZOHO_API_DOMAIN` | No | Overrides data_center if set |
| `ZOHOPY_LOG_LEVEL` | No | DEBUG/INFO/WARNING/ERROR (default: INFO) |
| `ZOHOPY_LOG_FORMAT` | No | console/json (default: console) |
